## [1.1.9] — 2026-11-23

- Zaktualizowano numer wersji Maven i pluginu.
- Zaktualizowano nazwę artefaktu GitHub Actions.
- Utrwalono balans zadań dziennych dla etapu midgame (XP i nagrody przedmiotowe).
- Poprawiono układ GUI zadań, w tym rozmieszczenie sekcji wymiarów.
- Zmiany kodu i konfiguracji obecne w gałęzi testowej obejmują również rozwój systemów NPC, kontraktów i zadań.
- Build GitHub Actions zakończył się sukcesem; artefakt został wygenerowany.
